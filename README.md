# 观象决（Guan Xiang Jue）

借物取数，结合八卦与六十四卦生成可解释的决策反思提示。

## 功能

- 按“第一眼为准，不挑不换”的方式记录数字
- 多位数逐位相加，循环映射到八卦
- 结合起卦时刻生成上下卦、动爻和变卦
- 给出“宜行 / 审慎行 / 暂缓”三档行动提示
- 展示完整计算过程和现实决策自问
- 支持桌面端与移动端

> 本项目用于文化体验、自我观察与决策反思，不构成医疗、法律或财务建议。

## 本地运行

```bash
npm install
npm run dev
```

## 验证

```bash
npm test
npm run lint
npm run build
```

## 技术栈

React 19、TypeScript、Vite、Vitest、Lucide React。
